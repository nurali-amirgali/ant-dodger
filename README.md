# ANT DODGER
ant dodger is a simple game where you play as an ant trying to collect cookies while dodging enemies

## HOW TO INSTALL
go to the [releases page](https://github.com/nurali-amirgali/ant-dodger/releases/tag/V1.0) and install the correct executable and run. 
Depending on the os the game might get flagged. thats normal as the game is unsigned. just click more info and run anyway.

## HOW TO PLAY
- use WASD or the Arrow keys to move
- collect the cookies and try to get the highest score
- avoid the enemies
- if you touch an enemy you lose a live
- you have 3 lives and if you lose them all you die
